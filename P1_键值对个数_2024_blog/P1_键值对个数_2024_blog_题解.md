# P1_键值对个数_2024_blog — 题解

> 项目：P1 ｜ 年份：2024 ｜ 来源：[UHO](https://theuho.site/2024/10/15/COexamsP1/)、[owpeter](https://owpeter.github.io/2024/10/15/CO/CO-p1-course/)

## 题解

博客给出的状态转移表（`S` 为当前状态，`chr` 为输入，`S'` 为次态）：

| S | chr | S' | 说明 |
| --- | --- | --- | --- |
| 0 | `{` | 1 | 进入当前集合 |
| 1 | other | 2 | 该序列不符合要求 |
| 1 | key 字符 | 3 | 用 cnt 记录 key 的长度 |
| 2 | `,` | 1 | 读取下一个序列 |
| 3 | `:` | 4 | 读到 `:`，进入 value |
| 4 | value 字符 | 4 | 读取 value，用 cnt 记录 value 的长度 |
| 4 | other | 2 | 该序列不符合要求 |
| 4 | `,` | 1 | 符合要求，each+1 |
| 4 | `}` | 0 | 集合结束，each 清零，total 取较大值 |

空格的判定：

> 在读取 key 或 value 时，若 cnt 为 0，说明空格出现在 key 或 value 之前，不影响判断，保持原状态；若 cnt 大于 0，说明空格出现在 key 或 value 之后，此时将变量 space 置 1，继续读取，如果 chr 仍是 key 或 value，说明不符合要求，将进入状态 2。
