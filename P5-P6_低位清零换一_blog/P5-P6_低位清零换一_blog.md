## 题目：从低位起将零位改为一

## 编码与汇编格式

博客未记录可验证的opcode/funct及完整位域编码；本文不分配编码。

语义操作数为 `rs、rt、rd`；助记符和实际汇编格式未记录。

## 描述

按位号 0 到 31 扫描 `GPR[rs]`，将遇到的前 `GPR[rt]` 个零位改为一；原来为一的位不计数。若零位不足，全部零位均改为一。结果写入 rd。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
R ← GPR[rs]
remaining ← U32(GPR[rt])
for i = 0 .. 31:
    if R[i] = 0 and remaining > 0:
        R[i] ← 1
        remaining ← remaining - 1
GPR[rd] ← R
```

## 边界与异常

这里的数量按 32 位无符号非负计数解释，而非仅取 rt 的低五位。数量为 0 时结果不变；数量不少于 rs 中零的总数时结果为 `0xffffffff`。
