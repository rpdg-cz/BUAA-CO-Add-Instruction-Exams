## 题目

T2 拆分数字

将输入整数 N 拆分为几个数相加的形式，按拆分项数降序排列，每项按数字大小升序排列（原文注：「giao记不清了」）。

输入

```
5
```

输出

```
1+1+1+1+1
1+1+1+2
1+1+3
1+2+2
1+4
```
