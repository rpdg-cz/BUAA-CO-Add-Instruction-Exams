## 题解

博主给出的伪代码（逐字摘录）：

```
i ← 0; j ← 0;
while (i<n && j<m) do
    while (A[i] <= B[j]) do
        print (A[i++]);
    end
    while (A[i] > B[j]) do
        print (B[j++]);
    end
end
while (i<n) do print(A[i++]); end
while (j<m) do print(B[j++]); end
```

- 复杂度 O(n+m)。
- 坑点 1：while 套 while 会让标号（label）变难，建议给每个 while 起不同名字注释；不考虑效率时内层 while 可写成 if。
- 坑点 2：博主用 `.space` 时"忘乘 4"，debug 很久。
- 数据范围较小，也可用类似计数排序的做法。
