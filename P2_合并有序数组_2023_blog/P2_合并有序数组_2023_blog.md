## 题名

合并两个非降序整数数组

## 题目描述

编写 MIPS 汇编程序，把两个分别按非降序排列的整数数组合并为一个非降序数组。输出必须保留两个输入中的所有元素及其重复次数。

## 输入输出与精确定义

逻辑输入为长度 m、n 以及数组 A[0..m-1]、B[0..n-1]。逻辑输出 C 长度为 m+n，满足 C 非降序，且每个值在 C 中的出现次数等于在 A、B 中的出现次数之和。相等元素可先取任一数组的元素，不影响数值结果。

例如 A=[1,2,2]、B=[2,3] 时，结果为 [1,2,2,2,3]。若允许空数组，则与空数组合并应保持另一数组；来源尚未确认长度能否为零。
