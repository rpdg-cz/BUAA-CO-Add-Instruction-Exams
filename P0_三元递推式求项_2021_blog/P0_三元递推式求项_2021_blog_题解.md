# P0_三元递推式求项_2021_blog — 题解

## 解题思路

对 N=0～3 直接返回初值。计算后续项时，同时保存三项旧值 x=S<sub>k−1</sub>、y=S<sub>k−2</sub>、z=S<sub>k−3</sub>，每步执行：

<pre>next ← x + (y and z)
(x, y, z) ← (next, x, y)</pre>

括号内的多目标赋值表示同一个时钟沿同时更新，右侧均使用更新前的值。逐项推进到 N 后输出 x。

三项寄存器须保留各自的历史值。若先覆盖 x，再依次把新 x 赋给 y、把新 y 赋给 z，会丢失前两项，破坏递推关系。

## 周期预算

最多计算到第 31 项，逐项运算次数小于 64。初始化、结束控制也计入 64 周期预算。
