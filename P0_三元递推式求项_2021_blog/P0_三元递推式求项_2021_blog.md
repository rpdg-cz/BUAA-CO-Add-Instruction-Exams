# P0_三元递推式求项_2021_blog

## 题目：三元递推数列的指定项计算

## 题目描述

设计 Logisim 时序电路，输入项号 N，求数列的第 N 项 S<sub>N</sub>。

## 数列定义

<pre>S<sub>0</sub> = 0
S<sub>1</sub> = S<sub>2</sub> = S<sub>3</sub> = 1
S<sub>n</sub> = S<sub>n−1</sub> + (S<sub>n−2</sub> and S<sub>n−3</sub>)    n ≥ 4</pre>

其中 and 表示按位与，+ 表示整数加法。

## 端口与限制

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| N | 输入 | 5 | 项号 0～31 |
| Nth | 输出 | 32 | S<sub>N</sub> |

电路须在 64 个周期内完成计算。该项号范围内的结果均可用 32 位表示。例如 S₄=2、S₅=3、S₆=3；N=0、1、2、3 时返回相应初值。
