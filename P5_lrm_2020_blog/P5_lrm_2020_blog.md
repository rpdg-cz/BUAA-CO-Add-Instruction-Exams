## 题目：由内存数据选择目的寄存器

## 编码与格式

opcode 及完整编码未记录。

汇编语法未记录；语义字段为 `base`、符号偏移 `offset`、数据源 `rt`。

## 描述

按基址加符号偏移读取一个内存字，将所读字的低 5 位解释为寄存器编号，把原 `rt` 的完整 32 位值写入该寄存器。内存只读不写。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
vAddr ← low32(GPR[base] + SEXT32(offset))
word ← MemoryWordAtByteAddress(vAddr)
dest ← unsigned(word[4:0])
GPR[dest] ← old(GPR[rt])
```

## 边界条件

目的编号在 0 至 31 之间；编号为 0 时写入被丢弃。目的寄存器恰为 `base` 或 `rt` 时，地址和写入数据仍取修改前的源值。普通整字读取限于课程合法的字对齐 DM 地址。
