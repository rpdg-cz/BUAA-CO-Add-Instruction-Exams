## 题目：非零同符号条件分支

## 编码与汇编格式

博客未记录可验证的opcode/funct及完整位域编码；本文不分配编码。

语义操作数为 `rs、rt、offset`；助记符、offset 字段宽度及实际汇编格式未记录。

## 描述

当 rs、rt 均不为零且符号位相同时，以本指令 PC+4 为基址进行相对分支；否则顺序执行。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
A ← GPR[rs]
B ← GPR[rt]
condition ← (A ≠ 0) AND (B ≠ 0) AND (A[31] = B[31])
if condition:
    target ← (PC + 4 + (SignExtend(offset) << 2)) mod 2^32
execute instruction at PC + 4
nextPC ← target if condition else (PC + 8) mod 2^32
```

## 边界与异常

零被明确排除；不能仅比较符号位。该指令不链接，不写通用寄存器。
