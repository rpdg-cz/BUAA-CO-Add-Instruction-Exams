# P2_消除游戏_2023_blog — 题解

> 项目：P2 ｜ 年份：2023 ｜ 来源：[fysszlr](https://www.fysszlr.top/2023/10/23/CO-P2%E4%B8%8A%E6%9C%BA%E8%AE%B0%E5%BD%95/)

## 题解

- 标程为递归，参数可减至一个；也可用位运算 O(1) 求解。
- 把 n 个数编号 0…n-1：奇数轮从 0 开始隔一个删一个 ⇒ 等价于"删除所有二进制末位为 0 的数"，答案该位赋 1；偶数轮从最后一个数开始 ⇒ 删除"二进制末位与最大数末位相同的数"，答案该位赋最大数末位的反。
- 统一写法：`(ans)₂[i] = 1 (i 为偶数) / (n)₂[i] (i 为奇数)`，其中 i 为二进制第 i 位；因编号从 0 开始，`(n)₂[i] == ~(n-1)₂[i]`，最后答案要加一。
- 伪代码（O(log n)）：

```
ans ← 0;
for i from 0 to log(n)-1 do
    if (i & 1) then ans ← ans | (2^i & n);
    else ans ← ans | 2^i;
    endif
end
ans ← ans + 1;
print(ans);
```

- O(1) 做法：`ans ← (n | 1431655765)`，再对 `2^⌈log n⌉` 取模、加一；其中 `1431655765 = 2^0 + 2^2 + … + 2^2k`。
