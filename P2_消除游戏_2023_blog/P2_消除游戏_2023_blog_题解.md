# P2_消除游戏_2023_blog — 题解

## 解题思路

每轮剩余序列仍是等差数列。维护首元素 head、相邻差 step、元素数 count，以及本轮方向 left。

<pre>head ← 1
step ← 1
count ← n
left ← true
while count &gt; 1 do
    if left or (count mod 2 = 1) then
        head ← head + step
    endif
    count ← count div 2
    step ← 2 × step
    left ← not left
endwhile
answer ← head</pre>

从左删除时必删去原首项；从右删除时，仅当当前元素数为奇数才删去原首项。每轮数量减半，因此时间 O(log n)、额外空间 O(1)。

## 自查

n=1 时为 1，n=2 时为 2，n=6 时为 4，n=9 时为 6。实际实现中应避免最后一轮之后无用的步长倍增引入位宽溢出。
