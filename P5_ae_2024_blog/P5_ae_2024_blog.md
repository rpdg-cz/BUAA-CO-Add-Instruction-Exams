## 题目：立即数与相邻位异或结果拼接

## 编码与格式

博客位域表：`op(6) | rs(5) | 00000 | imm(16)`；未给出 op 的固定值。

汇编语法未记录；结果写入字段 `rs` 指定的寄存器，固定零字段不是写回目的。

## 描述

保留立即数作为结果低 16 位。结果高 16 位的最低位等于立即数最低位，其余各位等于立即数当前位与前一位的异或。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
result[15:0] ← imm[15:0]
result[16] ← imm[0] XOR 0
for i = 1..15:
    result[16+i] ← imm[i] XOR imm[i-1]
GPR[rs] ← result
```

## 边界条件

`imm` 在此是 16 位位串，不做符号或零扩展后再运算。原 `GPR[rs]` 的值不参与计算。`imm=0x0000` 时结果为零；`imm=0xFFFF` 时结果为 `0x0001FFFF`。
