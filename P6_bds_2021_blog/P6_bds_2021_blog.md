## 描述

博客原文编号 `P6_L1_bds`（即 P6 上机第 1 题）。

指令名：`bds`

无符号大数除以小数

## 操作

```
Condition <- (0||GPR[rs]) >= (0||GPR[rt])
If Condition :
    LO <- (0||GPR[rs]) div (0||GPR[rt])
    HI <- (0||GPR[rs]) mod (0||GPR[rt])
else:
    LO <- (0||GPR[rt]) div (0||GPR[rs])
    HI <- (0||GPR[rt]) mod (0||GPR[rs])
```

## 示例

`bds $t1, $t2`

## 其他

该指令乘除阻塞周期与除法相同
