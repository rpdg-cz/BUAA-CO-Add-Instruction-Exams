## 题目：由奇偶性选择方向的循环移位

## 编码与汇编格式

博客未记录可验证的opcode/funct及完整位域编码；本文不分配编码。

语义操作数为 `rs、rt、rd`；助记符和实际汇编格式未记录。

## 描述

令移位量为 `GPR[rt][4:0]`。rt 为奇数时，将 rs 循环左移；rt 为偶数时，将 rs 循环右移，结果写入 rd。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
A ← GPR[rs]
B ← GPR[rt]
n ← U32(B[4:0])
if B[0] = 1:
    R ← ROL32(A, n)
else:
    R ← ROR32(A, n)
GPR[rd] ← R
```

## 边界与异常

`ROL32`、`ROR32` 均在 32 位字内循环，移出的位从另一端补入，不能用算术移位代替。n=0 时结果为 A；奇偶性只由 bit 0 决定，与有符号解释无关。
