## 题目：按符号选择目的寄存器的字节加载

## 编码与汇编格式

博客未记录可验证的opcode/funct及完整位域编码；本文不分配编码。

语义操作数为 `rt、offset、base`；助记符和实际汇编格式未记录。

## 描述

从 base+offset 指定的字节地址加载一个字节，按有符号字节解释并符号扩展到 32 位。负值写回 base 寄存器，零或正值写回 rt。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
EA ← (GPR[base] + SignExtend(offset)) mod 2^32
B ← Mem8[EA]
V ← SignExtend8To32(B)
dest ← base if B[7] = 1 else rt
GPR[dest] ← V
```

## 边界与异常

符号扩展由“字节小于0”的判定导出；零值属于写 rt 的分支。地址必须先用旧 base 计算，不能用加载后写回值重新计算。字节访问不要求字或半字对齐。
