# P5-P6_负字节写base_blog — 题解

## 解题思路

使用课程字节选择逻辑得到 B，再由 B[7] 同时决定符号扩展和目的编号。在数据返回前，可能的目的集合是 {base,rt}，去除0号并合并重复编号后处理相关。

## 实现核对

以[题面](P5-P6_负字节写base_blog.md)中的RTL为功能核对依据。源操作数取本指令执行前的状态，0号寄存器不接收写回；控制与目的编号须跟随产生它们的指令流水。不同实现可以选择不同流水级，只要冒险处理和最终可见行为符合题意。
