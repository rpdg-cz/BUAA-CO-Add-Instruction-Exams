## 题目：非负分支、无条件链接及未跳转时作废延迟槽

## 编码与格式

opcode 及完整编码未记录；不据标准同名指令补编码。

汇编语法未记录；源为 `rs`，分支位移为符号扩展的 `offset`。

## 描述

将 `rs` 按 32 位有符号补码解释。无论其正负均链接到 `P0+8`；非负时跳转且执行延迟槽，负数时不跳转并作废延迟槽。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
condition ← (S32(GPR[rs]) ≥ 0)
GPR[31] ← low32(P0 + 8)
if condition:
    execute instruction at P0+4 as the delay slot
    next_PC ← low32(P0 + 4 + SEXT32(offset || 00))
else:
    nullify instruction at P0+4
    next_PC ← low32(P0 + 8)
```

## 边界条件

零满足条件；`0x80000000` 为负数，不满足。作废的延迟槽指令不产生寄存器或内存副作用；链接写入仍然发生。

## 课程阶段注意

P5 为五级流水线 CPU，课程普通转移有一条延迟槽；本题若明确要求作废延迟槽，按本题的条件执行。非转移指令不自行产生控制转移。

本题作废条件是“不跳转”。停顿期间尚未完成分支决策时不得提前作废或丢失延迟槽；这是实现必须保持的架构效果。
