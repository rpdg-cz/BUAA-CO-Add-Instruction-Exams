## 题目：一位计数为奇数时分支并链接

## 编码与格式

原博客未记录 opcode 及完整位域。

汇编语法未记录；语义操作数为 `rs` 和有符号分支位移 `offset`。

## 描述

统计 `rs` 的全部 32 位中 1 的个数。计数为奇数时进行相对分支，并将 `P0+4` 写入 31 号寄存器；否则顺序执行且不写链接寄存器。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
n ← Σ(unsigned(GPR[rs][i])), i=0..31
if n mod 2 = 1:
    GPR[31] ← low32(P0 + 4)
    PC ← low32(P0 + 4 + SEXT32(offset || 00))
else:
    PC ← low32(P0 + 4)
```

## 边界条件

全零和全一的位计数分别为 0 和 32，均不跳转；符号位与其他位同样参与计数。分支条件与寄存器按有符号数解释后的正负无关。

## 课程阶段注意

P4 为 Verilog 单周期 CPU，无分支延迟槽。

原文跳转赋值与链接赋值共享同一旧 PC；链接不是跳转目标加 4。
