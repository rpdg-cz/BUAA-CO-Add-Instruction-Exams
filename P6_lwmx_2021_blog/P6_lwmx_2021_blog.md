## 描述

博客原文编号 `P6_L6_lwmx`（原文题号即为 L6，博客未给出 L3–L5；疑为博主只抄录了自己做的 3 题）。

指令名：`lwmx`

内存大于寄存器值时写入 5 号寄存器，否则写入 4 号寄存器

## 操作

```
Vaddr <- GPR[base] + sign_extend(offset)
Condition <- GPR[rt] < Memory[Vaddr]
If Condition:
    GPR[5] <- Memory[Vaddr]
else:
    GPR[4] <- Memory[Vaddr]
```

## 示例

`lwmx $t5, -100($0)`
