## 题目：相对跳转并链接至指定寄存器

## 编码与格式

原博客未记录 opcode、固定字段及字段位宽。RTL 使用 `imm` 与 `rt`，不得直接采用标准 `jalr` 编码。

汇编语法未记录；语义操作数为链接目的寄存器 `rt` 和有符号相对位移字段 `imm`。

## 描述

以本指令地址加 4 为基址，加上立即数字段左移两位后的有符号位移，无条件跳转，并将顺序后继地址写入 `rt`。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
target ← low32(P0 + 4 + SEXT32(imm || 00))
GPR[rt] ← low32(P0 + 4)
PC ← target
```

## 边界条件

先在字段末尾拼接两位 0，再符号扩展；不是零扩展。链接值由原 `P0` 计算，不使用更新后的跳转目标。若 `rt=0`，仍执行跳转。

## 课程阶段注意

P3 为 Logisim 单周期 CPU，无分支延迟槽。

链接值为 `P0+4`，本题不采用 P5 的 `P0+8`。
