# P1_逐位统计不同_2024_blog — 题解

## 解题思路

从 a 的最高位、b 的最低位开始逐位配对，累计不同的次数。

<pre>count ← 0
for i in 0 .. 31
    if a<sub>31−i</sub> ≠ b<sub>i</sub> then
        count ← count + 1
    endif
endfor</pre>

使用组合 always 块时，先将累计变量清零，再用阻塞赋值逐次累加。输出可能为 32，需要 6 位。

## 自查

a=b=0 时为 0；a 全 1、b 全 0 时为 32；a=b=0x80000000 时为 2。最后一例可区分逆向对齐与同下标配对。
