## 题解

> 一道简单的组合逻辑问题

```verilog
module different (
    input  [31:0] a, b,
    output [5:0]  count
);
    integer i;              // 用于循环计数
    reg [5:0] cnt;          // 定义一个计数变量
    always @(*) begin       // 组合逻辑
        // 初始化 cnt 为 0
        for (i = 31; i >= 0; i = i - 1) begin
            // 遍历 a 和 b 的每一位，如果对应位不同，则计数加 1
        end
    end
    assign count = cnt;
endmodule
```

（博客的 for 循环体在正文中省略为注释，只给出框架。）

### 补充题解（来自 owpeter）

> 似乎每年第一题都是一个类似的组合逻辑，都要使用 for 循环，所以大家一定要掌握 for 的使用方法

```verilog
integer i = 0;
always @ (*) begin
    for (i = 0; i < 32; i = i + 1) begin
        // ...
    end
end
```

> 然后，再来个 `reg[5:0] cnt` 就好啦。
