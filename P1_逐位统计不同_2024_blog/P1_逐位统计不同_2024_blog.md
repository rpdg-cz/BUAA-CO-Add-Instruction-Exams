# P1_逐位统计不同_2024_blog

## 题目：逆向对齐的两个位向量差异计数

## 题目描述

用 Verilog 实现组合逻辑模块。a 从最高位向最低位读取，b 从最低位向最高位读取，统计两者在对应读取位置上不同的次数。

## 模块接口

```verilog
module different (
    input [31:0] a, b,
    output [5:0] count
);
```

## 功能与范围

对 i=0～31，比较 a<sub>31−i</sub> 与 b<sub>i</sub>，count 为不相等的比较次数，范围为 0～32。

例如 a=b=0x80000000 时 count=2；a=0x80000000、b=0x00000001 时 count=0。
