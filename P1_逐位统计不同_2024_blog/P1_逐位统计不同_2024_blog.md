## 题目

> **Q1 vector a和vector b每位不同**
> a,b都是32位二进制数，a从左往右读，b从右往左读，判断a和b不同的位数。

模块接口（博客给出的题解框架即题面信号名）：

```verilog
module different (
    input  [31:0] a, b,
    output [5:0]  count
);
```
