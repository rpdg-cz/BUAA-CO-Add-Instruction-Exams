## 题名

逆向对齐的两个位向量差异计数

## 题目描述

用 Verilog 实现组合逻辑模块。a 从最高位向最低位读取，b 从最低位向最高位读取，统计两者在对应读取位置上不同的次数。

## 模块接口

```verilog
module different (
    input [31:0] a, b,
    output [5:0] count
);
```

## 功能与边界

对 i=0～31，比较 `a[31-i]` 与 `b[i]`，count 为不相等的比较次数，范围为 0～32。不要把 a[i] 与 b[i] 直接对齐比较。没有时钟、复位和内部状态。

例如 a=b=32'h80000000 时，反向对齐有两处不同，count=2；a=32'h80000000、b=32'h00000001 时 count=0。
