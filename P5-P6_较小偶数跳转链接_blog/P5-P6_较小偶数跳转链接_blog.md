## 题目：较小有符号数为偶数时分支并链接

## 编码与汇编格式

博客未记录可验证的opcode/funct及完整位域编码；本文不分配编码。

语义操作数为 `rs、rt、offset`；助记符和实际汇编格式未记录。

## 描述

把 rs、rt 解释为 32 位补码有符号整数。两数中较小者为偶数时，按 PC+4 与 offset 进行相对分支并执行延迟槽；否则取消延迟槽。无论条件是否成立，均将本指令 PC+8 写入 31 号寄存器。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
A ← GPR[rs]
B ← GPR[rt]
M ← A if S32(A) ≤ S32(B) else B
condition ← (M[0] = 0)
GPR[31] ← (PC + 8) mod 2^32
if condition:
    target ← (PC + 4 + (SignExtend(offset) << 2)) mod 2^32
    execute instruction at PC + 4
    nextPC ← target
else:
    annul instruction at PC + 4
    nextPC ← (PC + 8) mod 2^32
```

## 边界与异常

负偶数同样满足偶数条件，两源相等时任选其一不会改变结果。未跳转时仍链接，但延迟槽不得产生寄存器或存储器副作用。
