## 题目：零值条件寄存器跳转并链接

## 编码与汇编格式

来源编码：`opcode=000000`、rs、rt、rd、`shamt=00000`、`funct=110001`。来源格式仅有rs和rt，rd字段的固定值未记录；语义目的明确为31号而非rd。

`bezal rs, rt`（来源记录）。

## 描述

rt为零时，链接到31号寄存器，并在执行一条延迟槽后跳转到旧rs值；rt非零时顺序执行且不链接。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
target ← GPR[rs]
condition ← (GPR[rt] = 0)
if condition:
    GPR[31] ← (PC + 8) mod 2^32
execute instruction at PC + 4
nextPC ← target if condition else (PC + 8) mod 2^32
```

## 边界与异常

两种情况均执行PC+4处延迟槽。rs=31时目标取写链接前的源值；条件不成立时31号寄存器不变。
