# P2_三道汇编题_2020_blog

## 题目：三道 MIPS 汇编程序设计题

## 第一题：素数判断

判断一个整数是否为素数。素数是大于 1 且只有 1 和自身两个正因数的整数；0、1 和负数不是素数。

## 第二题：约瑟夫环

在循环队列中按报数规则反复删除元素。

## 第三题：快速排序翻译

将给定的递归快速排序程序译为 MIPS 汇编。

## 补充条件

1. 三道题分别提交独立程序，均使用 MARS、Compact, Data at Address 0、无延迟槽，可用伪指令，syscall 10 结束；输入十进制整数以空白分隔，不输出提示。所有比较按有符号数进行，输出行末有换行。

2. 素数判断：输入一个 32 位有符号整数 x；素数输出 1，否则输出 0，各占一行。

3. 约瑟夫环：输入 n、m、s，1≤n≤100、1≤m≤10000、1≤s≤n。人员编号 1～n 按升序循环，从 s 开始且 s 报 1，每逢报到 m 淘汰该人，下一存活者重新报 1；直到全部淘汰。输出全部淘汰编号一行，用单个空格分隔，最后一人即幸存者，不另输出一行。

4. 快速排序：输入 n（0≤n≤100），再输入 n 个 32 位有符号整数，按下方给定的原地递归算法翻译；输出升序数组一行，数之间单空格无尾空格，n=0 时输出一个空行。数组下标从 0 开始，区间为两端闭合。


### 第三题待翻译 C 代码

```c
void quicksort(int a[], int l, int r) {
    if (l >= r) return;
    int pivot = a[r], i = l - 1;
    for (int j = l; j < r; ++j) {
        if (a[j] <= pivot) {
            ++i;
            int t = a[i]; a[i] = a[j]; a[j] = t;
        }
    }
    int p = i + 1;
    int t = a[p]; a[p] = a[r]; a[r] = t;
    quicksort(a, l, p - 1);
    quicksort(a, p + 1, r);
}
```

读入后调用 `quicksort(a, 0, n - 1)`，最后按输入输出约定打印数组。
