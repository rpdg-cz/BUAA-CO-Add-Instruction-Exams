# P0_MD5前处理电路_2020_blog

## 题目：带 10101 标记的二进制串填充电路

## 题目描述

设计 Logisim 组合逻辑电路。输入为 32 位二进制串，由若干前导零、标记串 `10101` 和待处理串 u 依次拼接而成。u 的长度为 L，0 ≤ L ≤ 27。

若 L < 27，在 u 后附加一个 1，再附加足量的 0，使所得 u′ 恰为 27 位；若 L=27，则 u′=u。结果由 u′ 和原长度 L 组成。

## 填充规则

<pre>if L &lt; 27 then
    u′ ← u || 1 || 0<sup>26−L</sup>
else
    u′ ← u
endif</pre>

|| 表示位串拼接。L=0 时补成一个 1 后跟 26 个 0；L=27 时保持原串。长度字段使用补位前的 L。

## 补充条件

1. 端口为 32 位无符号 input 与 32 位 output，纯组合逻辑，无时钟或复位。按 input[31] 到 input[0] 从高位向低位扫描，首次完整出现的 10101 为标记，其右侧所有位为 u，u 的首位即使为 0 也计入长度。输入保证符合题面前导零、标记、u 的形式。

2. 输出定义为 output={u′[26:0],L[4:0]}，高 27 位为填充后数据，低 5 位为补位前长度。这里为位串拼接，不作算术相加，也不作大小端字节重排。

3. L=0 时 u 是空串；L=27 时不追加 1。u 内可以再次含有 10101，仍以最先扫描到的标记为准。
