# P0_字符自动机_2021_blog

## 题目：“2021 或 2011”字符自动机

## 题目描述

设计 Logisim Mealy 状态机，处理与字符序列 `2021`、`2011` 有关的识别任务。

## 补充条件

1. 输入 clk、同步高有效 reset、8 位 ASCII 字符 chr；输出 1 位 hit。每个非复位 clk 上升沿接收一个字符。开始前先复位，复位沿清空已接收前缀；复位后第一普通沿即接收第一个字符。

2. hit 是 Mealy 组合输出：当沿前已保存的前缀与当前 chr 拼成以当前字符结束的 2021 或 2011 时为 1，否则为 0；reset=1 时强制为 0。测试在接收沿采样 hit，输出不另加一拍延迟。

3. 连续输入允许匹配重叠，不跳过任何字符。非数字及目标串以外的字符仍正常接收，并按最长有效后缀恢复匹配；匹配成功后同样保留可继续匹配的最长有效后缀。不统计次数。
