# P1_键值对个数_2024_blog

## 题目：字符集合中的合法键值对计数

## 题目描述

用 Verilog 状态机串行接收字符。集合用 `{`、`}` 包围，候选键值对用逗号分隔，键和值之间用冒号分隔。键至少含一个字符，只能含英文字母和数字，且首字符必须为字母；值至少含一个字符，只能含十进制数字。

输入结构保证为 `xxxx{xxxx:xxxx,···,xxxx:xxxx}xxxx`，其中 `xxxx` 不含 `{`、`:`、`,`、`}`。

字段外、结构分隔符之间的空格不影响匹配；字段内部不能插入空格。例如 `ab : 12` 合法，`a b:12` 和 `ab:1 2` 不合法。

## 端口与计数

每个 clk 上升沿读取 chr；rst 为高电平有效的异步复位。each 和 total 均为 8 位输出：each 表示当前集合中已识别的合法键值对数，total 表示单个集合合法键值对数量的历史最大值。

逗号结束一个合法项时，each 增加 1；读到 `}` 时，先把最后一个合法项计入集合最终数量，按该数量更新 total，再将 each 清零。

## 补充条件

1. chr 是 8 位 ASCII，每个非复位 clk 上升沿接收一字节；只有 ASCII 空格 0x20 享受题面空格规则，字母仅 A～Z/a～z，数字仅 0～9，其他普通字节使其所在字段非法。rst 异步置高立即清空解析状态，each=total=0，回到集合外；解除复位后第一沿正常接收。

2. 每个非空候选项恰有一个冒号，逗号分项；集合可以为空（{} 或仅空格），空或仅空格的候选项允许没有冒号，也允许空字段，它们都不计数。不嵌套；一串中允许多个集合，集合外遇到 { 开始新集合，其余字符忽略。相同键名的不同合法候选项分别计数，不去重。

3. each=min(本集合已由逗号确认的合法项数,255)；total=min(已结束各集合合法项总数的最大值,255)。计数饱和后仍继续解析所有输入。尚未结束的最后一项不提前计入 each；右括号沿以包括末项的饱和值更新 total，再令 each=0。
