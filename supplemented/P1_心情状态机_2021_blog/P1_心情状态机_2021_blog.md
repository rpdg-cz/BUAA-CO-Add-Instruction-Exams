# P1_心情状态机_2021_blog

## 题目：带连续周期计时条件的心情状态机

## 题目描述

用 Verilog 实现时序状态机。某些状态在连续 n 个时钟周期未受到指定输入打断后转移；打断输入也可能触发状态转移。

## 状态片段

输入为 IDEA 时转入 BUSY，并将当前段的计时器清零。计时量表示当前连续未被打断的周期数；打断导致重新开始计时时，计时器清零。

## 补充条件

1. 输入 clk、同步高有效 reset、evt[1:0]；输出 mood[1:0]。事件编码 00=NONE、01=IDEA、10=REST、11=PRAISE；状态编码 00=IDLE、01=BUSY、10=HAPPY、11=TIRED。运行先复位，复位优先并令 mood=IDLE、计时器=0，复位沿不消费事件。

2. 每个普通 clk 上升沿先处理事件：任何状态收到 IDEA 都转 BUSY，REST 都转 IDLE，PRAISE 都转 HAPPY，并清零连续计时器；包括事件目标与当前状态相同时也重新计时。事件优先于同沿的超时。

3. 仅 NONE 计入连续未打断周期：BUSY 连续 3 个 NONE 后转 TIRED；HAPPY 连续 2 个 NONE 后转 IDLE；TIRED 连续 2 个 NONE 后转 IDLE；IDLE 收到 NONE 保持。每次超时转移清零计时器，进入状态的事件沿不算一个 NONE。mood 沿后立即反映新状态。
