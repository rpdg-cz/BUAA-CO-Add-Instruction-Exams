# P1_心情状态机_2021_blog — 题解

## 解题思路

使用 2 位 mood 和 2 位 cnt。cnt 是进入当前状态后已经连续收到的 NONE 数量；进入状态或任何非 NONE 事件都清零。优先级为 reset、非 NONE 事件、NONE 下超时/计数。IDLE 的 cnt 保持 0。

NONE 且 BUSY 时，旧 cnt=2 则转 TIRED 并清零，否则 cnt+1；HAPPY/TIRED 时，旧 cnt=1 则转 IDLE 并清零，否则 cnt+1。这样阈值 T 在第 T 个 NONE 沿触发，而不是再晚一拍。

复位后输入 IDEA、NONE、NONE、NONE，沿后 mood 为 BUSY、BUSY、BUSY、TIRED。若第三个 NONE 改为 IDEA，则保持 BUSY 且计时归零；此后仍需三个新的 NONE 才转 TIRED。PRAISE 进入 HAPPY 后两个 NONE 回 IDLE。
