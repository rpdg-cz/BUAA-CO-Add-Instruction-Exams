# Pre_三题概述_2023_blog — 题解

## 解题思路

第一题维护 h=0、best=0，循环读 Δh 后先做 h+=Δh，再做 best=max(best,h)。包括初始位置保证结果不会负。n=0 输出 0；变化量 −2、3、−1 时海拔为 0、−2、1、0，答案 1。最大累计绝对值为 10^9，32 位有符号加法安全。

第二题用三个无符号比较器与一个 AND：ans=(data[15:12]≤data[11:8]) && (data[11:8]≤data[7:4]) && (data[7:4]≤data[3:0])。0x122F 输出 1，0x1232 输出 0，0xFFFF 输出 1。

第三题先判断 code 非零且 code & (code−1)=0，再对独热位编码为 p。用 3 位 prev 和 1 位 valid 保存历史，2 位寄存器保存 result。复位清零；无效输入只令 result=00；首次有效输入令 prev=p、valid=1、result=00；其余有效输入比较后更新 prev。

复位后输入 00000100、00100000、00100000、00000010，输出 00、11、10、01；中间插入 00000000 或 00000011 时该拍输出 00，并且不改变下一拍的比较基准。三个子题共享题目目录，但不共享输入协议或电路状态。
