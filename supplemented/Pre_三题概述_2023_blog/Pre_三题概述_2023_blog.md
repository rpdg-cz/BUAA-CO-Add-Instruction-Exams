# Pre_三题概述_2023_blog

## 题目：Pre 综合程序与电路设计

## 第一题：最高海拔（MIPS）

初始海拔 h₀=0，输入 n 个相对变化量 Δhᵢ，满足 hᵢ=hᵢ₋₁+Δhᵢ，求 max(h₀,h₁,…,hₙ)。初始位置也计入最高海拔；若所有到达位置的海拔均为负，答案为 0。

输入为 n 和 n 个变化量，输出为一个最高海拔。

## 第二题：四数非降序判断（Verilog）

输入 16 位 data，每 4 位表示一个数，共四个数。若四数按读取顺序构成非降序列则输出 1，否则输出 0。非降序列允许相邻元素相等。

## 第三题：独热码状态机（Logisim）

串行接收 8 位独热码，按三种情形输出不同结果。每个独热码恰有一位为 1。

## 补充条件

1. 三题独立完成。最高海拔题使用 MARS、Compact, Data at Address 0、无延迟槽，可用伪指令，syscall 10 结束。按空白分隔依次输入 n（0≤n≤1000）和 n 个整数 Δh（−1000000≤Δh≤1000000），输出一个十进制最高海拔及换行，不打印提示。所有累计海拔可由 32 位有符号整数精确保存。

2. 四数非降序题为纯组合 Verilog 模块：输入 data[15:0]，输出 1 位 ans，无时钟/复位；依次比较 data[15:12]、[11:8]、[7:4]、[3:0] 四个无符号数，允许相等。

3. 独热码题输入 clk、同步高有效 reset、code[7:0]，输出 result[1:0]；每个普通上升沿接收一个编码，沿后输出该次比较结果。复位优先、清空上次有效位置并令 result=00，开始前先复位，复位后第一份有效独热码输出 00 并保存其 1 所在位号。

4. 独热码位号从最低位 0 到最高位 7。以后把本次位号 p 与上次有效位号 q 比较：p<q 输出 01，p=q 输出 10，p>q 输出 11，并保存 p。若 code 不是恰一位为 1，则本次输出 00，保留上次位置和是否已有有效位置；后续输入继续比较。
