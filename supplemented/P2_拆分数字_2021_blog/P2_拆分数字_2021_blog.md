# P2_拆分数字_2021_blog

## 题目：整数的加法拆分输出

## 题目描述

编写 MIPS 汇编程序，将输入整数 N 表示为若干整数之和，并输出拆分结果。各项按数字大小升序排列，拆分按项数降序排列。

## 输入输出片段

输入：

```text
5
```

输出片段：

```text
1+1+1+1+1
1+1+1+2
1+1+3
1+2+2
1+4
```

每行内部以加号连接，各项之间没有空格。

## 补充条件

1. 环境为 MARS，Compact, Data at Address 0，不考虑延迟槽，允许 MARS 伪指令，使用 syscall 10 结束。输入仅一个十进制整数 N，1≤N≤20。

2. 输出 N 的全部至少含两项的正整数非降序拆分，不同排列只输出一次；不输出单独的 N。先按项数从多到少，同项数按数字序列的数值字典序从小到大。原 N=5 输出块为片段，完整结果还包括最后一行 2+3。

3. 每个拆分独占一行，相邻项之间仅一个 +，行末一个换行，不输出提示、空格或空行。N=1 时没有拆分，输出为空。
