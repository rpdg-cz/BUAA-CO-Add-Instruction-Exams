# Pre_LogisimFSM_2024_blog

## 题目：操作码控制的数列生成 Moore 状态机

## 题目描述

设计 Logisim Moore 状态机，根据每次的 2 位 type 生成下一项数列，并输出 32 位结果。

- type=0 时，本项为 0。
- type=1 时，本项为上一项加 1。
- type=2 时，本项与此前数列项的和有关。

## 端口与时序

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| clk | 输入 | 1 | 时钟 |
| reset | 输入 | 1 | 同步复位 |
| type | 输入 | 2 | 操作选择 |
| output | 输出 | 32 | 当前输出项 |

加法溢出保留低 32 位。Moore 输出来自当前保存的状态，同步复位在有效时钟沿更新状态。

## 补充条件

1. reset 为高有效同步复位，clk 上升沿更新，优先于 type；开始前先复位。复位后当前项 a₀=0、历史和 S₀=0，output=a₀；复位沿不生成新项，首个普通沿生成 a₁。

2. 令 Sₙ=a₀+…+aₙ。普通采样沿依 type 生成 aₙ₊₁：0→0；1→aₙ+1；2→Sₙ（采用此前各项和）；3→aₙ（保持项值）。无论哪个 type，该普通沿均生成一个新项，并更新 Sₙ₊₁=Sₙ+aₙ₊₁。

3. a、S 和 output 均为 32 位无符号位串，所有加法模 2³²；type=0 只令新项为 0，不清历史和。type=3 虽保持 output，仍把重复项加入历史和。output 直接取当前项寄存器，沿后立即更新。电路外观与题面端口一致即可。
