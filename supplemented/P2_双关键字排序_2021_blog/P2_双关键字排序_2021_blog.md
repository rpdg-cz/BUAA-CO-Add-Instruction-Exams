# P2_双关键字排序_2021_blog

## 题目：双关键字排序

## 题目描述

编写 MIPS 汇编程序，对具有两个排序关键字的记录进行排序。先比较第一关键字，第一关键字相同时再比较第二关键字。

## 输入输出

输入为一组带两关键字的记录，输出为按复合次序排列后的同一组记录。记录中的字段保持关联，记录不得丢失或重复。

## 补充条件

1. 使用 MARS、Compact, Data at Address 0、无延迟槽，允许伪指令，syscall 10 结束。输入 n（0≤n≤100），随后 n 条记录，每条按 key1 key2 payload 次序给出三个 32 位有符号十进制整数，以空白分隔。

2. 第一关键字 key1 升序；相同时第二关键字 key2 升序；两关键字均相同时保持输入先后次序。payload 是随记录移动的数据，不参与比较。相同 payload 不合并记录。

3. 输出排序后 n 条记录，每条一行，字段仍为 key1 key2 payload，字段间单空格无尾空格，每行以换行结束；n=0 时输出为空，不打印提示。
