## 题面范围

题面只保留题名、编码、格式、功能描述、操作、直接影响行为的限制/异常和实例。删除出处、整理过程、缺资料/未核实/不代表原题等声明、重复通用 glossary、泛泛课程说明。来源、判残证据、版本冲突和删去的维护说明保存在各题隐藏的 `.exercise.json`，题解也移除此类套话，保留实际推导与实现内容。题目身份/状态继续由目录和管理界面表达。

缺编码用 `x`：只保留已经确定的位域/固定位，未知位以等宽的 x 串表示；完全没有位域依据时用 32 个 x 表示整条指令，不能凭 R/I/J 习惯补造字段或固定零位。未知汇编语法不编造；省略格式章，而不是写一段缺项说明。残题仅列可确认的描述或操作片段，不擅自补全行为，也不能把“资料不明”替换成具有架构含义的 UNPREDICTABLE。

Pre/P0/P1/P2 题保留具体任务、输入输出、端口/位宽、时钟复位、功能/状态表、算法和样例，不能硬套 MIPS 指令编码模板。

## 操作符号

- 赋值 `←`；相等/不等 `=`、`≠`；条件 `if ... then` / `else` / `endif`；循环 `for i in 0 .. 31` / `endfor`，避免 Python 冒号、`+=`、三元表达式、C 的 `<<`/`>>`。
- 位选择用下标 `x` 的 `31..0`，不能保留 `x[31:0]` 风格；`GPR[rs]` 的方括号是寄存器索引，不能去掉。拼接 `||`；重复位 `0` 的上标 n；逻辑 `and`、`or`、`xor`、`nor`；整数除法 `div`，余数 `mod`。
- 使用 `sign_extend`、`zero_extend`；课程原题采用的 `one_extend` 可保留。避免 `S32/U32/SEXT32/low32/low64/SignExtend` 等自造别名。低 32 位用 `temp` 下标 `31..0` 表示。
- `< > ≤ ≥` 按手册表示补码比较。无符号 32 位比较按 SLTU 写 `(0 || A) < (0 || B)`，不能直接去掉 U32 改成有符号比较。计数字段/下标按其非负整数意义使用。
- 只做格式转换，不改变寄存器源、条件写回、边界、访问宽度或异常。内存可沿用官方课程题的 `vAddr`、`memword`、`memory[vAddr]`，不把课程访存强行扩成 TLB 模型。
- 普通顺序 PC 自增省略。P3/P4 转移无延迟槽，直接 `PC ← PC + 4 + target_offset`。P5–P7 在 `I:` 计算条件/偏移、链接 `PC + 8`，在 `I+1:` 提交 PC；按 BEQ 用 `PC ← PC + target_offset`，不要多加 4。绝对目标可以在 I: 用 target 暂存再在 I+1: 写 PC。
- 作废延迟槽用 `NullifyCurrentInstruction()`，位置按手册放在 I+1:；不得保留“execute instruction at P0+4”等英文叙述或 `next_PC/P0` 别名。
- 自定义运算尽量展开为手册的赋值、位域、拼接、条件/循环。若保留抽象函数，必须有题意支持且清楚定义，不能用未定义的 helper 掩盖行为缺项。
- 已知编号的 CP0 寄存器按 `CPR[0, 编号, 0]` 表示。编号未给的新增命名寄存器可直接使用其题意定义的名称，不编编号，也不使用 C 风格 `CP0.field`。
- 手册 `mod` 是补码余数。EAM 要求 0..16 的数学非负余数，因此负余数须再加 17，不能在更换记号时丢失该行为。

## Markdown 表示
