# 博客题整理与纳管决定

## 范围与依据

原始导入保存在提交 `8f10f0b`，93 个 `_blog` 目录，覆盖 Pre、P0～P7 及 P5-P6。逐题阅读题面和已有题解，核对来源博客、图片、被文本抽取漏掉的 MathJax SVG，以及本地课程教程；整理不是恢复官方评测附件，不自行出题。

按用户明确要求，缺 opcode/funct 不构成残题。对核心数学功能可确定、仅原评测信号名或接口协议未保存的题目，单列接口适配说明；对会改变可观察结果的关键分支、比较符号、状态转移或相互冲突的记述，保留未决并归档，不增设练习约定。

本轮为 59 个行为可还原的博客条目、33 个残题和 1 个残缺自拟参考设想。原有 23 题及其 TS/class 不变。`lww` 来自博主设想，明确标为非考题记录。正文与题解分开，原始目录名保留以维持引用；少数原目录概述不准确时，以校勘后的正式题名和正文为准。

- Hugo 图片补回导航完整转移和序列检测映射，不使用另一来源自称记错的映射。
- 上游第一手记录补齐 lwmx 有符号比较、jap 目标拼接、lwld 的无符号阈值。

三组独立复审覆盖全部 93 份题面与 85 份题解，实质发现均修正或保留为具名未决项。文中的本地课程教程引用改为明确的路径文本，避免发布本仓库不存在的外链路径。

## 管理模型

- 根目录存放正常条目；`incomplete/<id>/` 集中存放行为残缺记录。只定向扫描两层，basename ID 在两处唯一，API 不接受路径作为 ID。
- `status` 为 complete/incomplete，状态变更移动整题；`relativePath` 供 README 使用。残题仍支持详情、编辑、附件和删除。
- 允许中文 ID/题解文件名，同时保持路径分隔符、隐藏名、保留容器、Windows 设备名（含 COM/LPT 的上标 ¹²³）检查。归档容器和成员拒绝链接。
- `scriptName`/语言/源码均可省略，纯题面保存不会生成空 TS。文件名仍不决定助记符。
- 阶段保留 Pre 和 P5-P6；来源区分课程链接、博客回忆和博主自拟，不能从博客造出 ProblemId。
- 同题下载及文件修改使用稳定 ID 的读写队列。等待文件句柄完全关闭再删除、覆盖或移档，迁移后的排队下载在执行时重新定位；不同题目并行，失败不污染后续队列。
- README 统一索引列出状态、来源及实际相对路径，保留人工前后文；残题审计记录见 incomplete/README.md。
