## 题目

> **Q2 奇偶交替数列**
> 一个数列由 01 组成，连续的 0 或者 1 的个数分别为奇偶，则符合要求，如 `001110000111` 符合奇偶交替数列，`0011100001110` 不符合。每个时钟上升沿读入 number，如果是奇偶交替数列，则 check 为 1，否则为 0。res_n 为异步复位信号，低电平有效。

模块接口：

```verilog
module alternate (
    input  clk, res_n, number,
    output check
);
```
