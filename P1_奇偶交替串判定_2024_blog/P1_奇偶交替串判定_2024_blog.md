## 题名

连续同值段长度的奇偶交替判定

## 题目描述

用 Verilog 时序模块逐位接收 0、1。将已接收前缀划分为极大的同值连续段，要求相邻段的长度一奇一偶。

例如 `001110000111` 的段长为 2、3、4、3，满足要求；追加一个 0 后段长为 2、3、4、3、1，最后两段均为奇数，不满足。

## 模块接口与时序

```verilog
module alternate (
    input clk, res_n, number,
    output check
);
```

每个 clk 上升沿接收一位 number，res_n 为低电平有效的异步复位。来源要求符合时 check=1，否则为 0。

## 输出规则与边界

- 空前缀和只有一种输入值的前缀输出 `check=0`。owpeter 明确给出 `00`、`111` 不满足要求，UHO 的判定也要求两类段均已出现。
- 当前前缀至少含两段，且每对相邻段的长度奇偶不同，才输出 `check=1`。
- 当前末段还未结束，其长度奇偶随同值输入变化，因此暂时的 `check=0` 可以恢复。例如 `001` 输出 1，`0011` 输出 0，`00111` 又输出 1。
- 已结束的两个相邻段若同奇偶，该错误不会被后续输入消除，直到复位。不能把末段尚未结束时的暂时不匹配提前锁成历史错误。
