# 本地题目管理页面

一个零依赖的本地 Web 页面，用来浏览、检索和维护本仓库的加指令练习。
后端只使用 Node.js 内置模块，不需要 `npm install`，也没有构建步骤。

## 快速开始

```bash
node tools/exercise-web/server.js
```

然后打开 <http://127.0.0.1:8787/>。管理入口是 <http://127.0.0.1:8787/#admin>。

需要 Node.js 18 或更新版本（用到内置 `fetch`、`node:test`）。仓库根目录必须保持为本仓库，服务会直接读写仓库里的题目目录。

## 能做什么

**浏览**

- 左侧按阶段（P3 / P4 / P5）列出全部练习，支持关键字与阶段筛选。
- 右侧渲染题面（Markdown + 题面里的 HTML 表格）、查看 TS 定义、下载 `.class` 等附件。
- **查看原题**：从题面首行的 `> 项目：… ｜ 题目 ID：… ｜ 来源 PieId：…` 还原课程平台链接，可直接跳回原题页面，另有「复制链接」按钮。

**管理模式**

- 新增题目：填写题目 ID、指令名、题面和 TS 定义，可同时上传附件。
- 编辑题面 / TS 定义、改名指令（会同步重命名 `.ts`）、删除附件。
- 删除题目（直接删除目录，误删可用 `git checkout` 恢复）。
- **同步 README 索引**：按目录重新生成 `README.md` 底部的题目表格；列表页会提示索引是否落后。

## 数据与约定

页面不维护数据库，题目目录就是唯一数据源，读到的内容和 `git` 里的完全一致。

| 约定 | 说明 |
| --- | --- |
| 目录名 | 即题目 ID，如 `P5_L6_lbget_2022`，只允许字母、数字、`_`、`.`、`-` |
| 题面 | `<目录名>.md`，首行 `# 标题`，第二段 `> 项目：… ｜ 题目 ID：… ｜ 来源 PieId：… ｜ 类型：…` |
| TS 定义 | 目录内唯一的 `.ts`，文件名即指令名 |
| 附件 | 其余文件，通常为 `<指令名>.class` |

README 表格的行序为：阶段 → `_L<编号>`（`_M_` 排在最后）→ 目录名。

## 配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 监听端口 |
| `HOST` | `127.0.0.1` | 监听地址 |
| `CO_ADMIN_TOKEN` | 空 | 设置后，所有写操作都要带 `X-Admin-Token` 请求头，页面在管理栏填写 |
| `CO_PROBLEM_BASE_URL` | `http://cscore.buaa.edu.cn/#/problem` | 「查看原题」链接的前缀 |
| `CO_REPO_ROOT` | 仓库根目录 | 指向别的题目目录时使用 |

## 安全边界

- 默认只监听 `127.0.0.1`，不对局域网开放。
- 未设置 `CO_ADMIN_TOKEN` 时，写操作只接受来自本机回环地址的请求；即使误把 `HOST` 改成 `0.0.0.0`，远程写操作也会被拒绝，除非显式配置令牌。
- 题目 ID、文件名都做了白名单校验，写文件前会做路径越界检查。

## 测试

```bash
node --test tools/exercise-web/test/
```

覆盖题目排序与原题链接解析、增删改查、路径穿越拦截、README 索引幂等性，以及 HTTP 接口。其中一条用例会校验仓库内 `README.md` 的索引与当前目录一致，新增题目后忘记同步会失败。

## 目录结构

```text
tools/exercise-web/
├── server.js            HTTP 服务、路由与静态资源
├── lib/
│   ├── exercises.js     题目目录的读取、校验与增删改
│   ├── readme.js        README 索引表格的生成与同步
│   └── markdown.js      题面渲染（Markdown + 内嵌 HTML）
├── public/              浏览与管理页面
└── test/                冒烟测试
```
