# P1_加权投票计分_2020_blog — 题解

> 项目：P1 ｜ 年份：2020 ｜ 来源：[owpeter](https://owpeter.github.io/2024/09/12/CO/BUAA-CO-%E5%89%8D%E4%BC%A0/)、[roife](https://roife.github.io/posts/buaa-co-lab-p1/)

## 题解

- 数 1 的个数再按权重加权：`cnt = popcount(np)*1 + popcount(vip)*4 + vvip*16`，`cnt >= 32` 则 `res = 1`。

```verilog
`timescale 1ns / 1ps
module test(
    input  [31:0] np,
    input  [7:0]  vip,
    input         vvip,
    output reg    res
);
    integer i;
    reg [31:0] cnt;
    always @(*) begin
        cnt = 0;
        for (i = 0; i < 32; i = i + 1) if (np[i])  cnt = cnt + 1;
        for (i = 0; i < 8;  i = i + 1) if (vip[i]) cnt = cnt + 4;
        if (vvip == 1) cnt = cnt + 16;
        if (cnt >= 32) res = 1;
        else           res = 0;
    end
endmodule
```

- 博客提醒：`for` 循环、`if` 判断等都需要在 `always` 块中使用；`always @ (*)` 用的较少，此用法可以当组合逻辑使用；**计数器别忘了初始化**，否则将恒为 `xxx....`。
