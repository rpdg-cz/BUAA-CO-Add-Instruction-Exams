## 题目：按位计数奇偶决定循环移位

## 编码与格式

`000000 | rs(5) | rt(5) | rd(5) | 00000 | 001010`。

`swc rd, rs, rt`。

## 描述

根据 `GPR[rt]` 中 0 的个数的奇偶性，决定将 `GPR[rs]` 循环左移或右移后写入 `rd`。移位量取 `GPR[rt][4:0]`。`GPR[rt]` 的整个 32 位值为 0 时，按来源的特殊规定不进行写回。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
A ← GPR[rs]
B ← GPR[rt]
n ← unsigned(B[4:0])
if B ≠ 0:
    if number_of_one_bits(B) mod 2 ≠ 0:
        GPR[rd] ← ROTL32(A, n)
    else:
        GPR[rd] ← ROTR32(A, n)
PC ← low32(P0 + 4)
```

## 边界条件

`ROTL32`、`ROTR32` 分别表示 32 位循环左移、循环右移，移位量为 0 时都返回原位串。统计 1 与统计 0 的奇偶性相同，因为总位数为 32。条件 `B=0` 与 `n=0` 不等价：前者不写回；若 `B` 非零而低 5 位为 0，则仍按规则将 `A` 写入 `rd`。

## 课程阶段注意

P5 为五级流水线 CPU，课程普通转移有一条延迟槽；本题若明确要求作废延迟槽，按本题的条件执行。非转移指令不自行产生控制转移。
