## 描述

博客原文编号 `P5_L1_swc`（即 P5 上机第 1 题）。

指令名：`swc`

条件循环移位，如果寄存器值含奇数个零则循环左移，含偶数个零则循环右移

## 操作

```
Condition <- GPR[rt]_{31} + GPR[rt]_{30} + … + GPR[rt]_{0}
temp <- GPR[rt]
If Condition % 2 != 0:
    GPR[rd] <- ( GPR[rs]_{(31-temp)…0} || GPR[rs]_{31…(31-temp+1)} )
else:
    GPR[rd] <- ( GPR[rs]_{(temp-1)…0} || GPR[rs]_{31…temp} )
```

## 示例

`swc $t1, $t2, $t3`

## 其他

若 `GPR[rt]` 值为 0 则相当于无操作
