## 题目：加载后无溢出才累加至链接寄存器（地址字段缺失）

## 编码与格式

opcode、格式与offset字段位宽未记录。

## 描述

读取rs加offset地址的内存字，尝试与31号寄存器相加；用33位符号扩展加法判断32位有符号溢出，只在未溢出时保存和。读数据及条件累加含义清楚，地址偏移解释没有写全。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
mem_data ← mem[GPR[rs] + offset]
temp ← low33((GPR[31][31] || GPR[31]) + (mem_data[31] || mem_data))
if temp[32] = temp[31]:
    GPR[31] ← temp[31:0]
else:
    do not write GPR[31]
```

## 边界条件

temp最高两位相同时无有符号溢出，最高两位不同时保留31旧值。offset是否符号扩展、是否拼接00、其位宽与地址对齐规则不能从未声明的offset直接确定。
