## 题目：负值条件变距分支并链接

## 编码与汇编格式

博客未记录可验证的opcode/funct及完整位域编码；本文不分配编码。

语义操作数为 `rs、rt、offset`；助记符和实际汇编格式未记录。

## 描述

当 rs 的 32 位补码值为负时，按 offset 与 `2^k` 组合的指令条数改变控制流，其中 `k=rt[1:0]`。条件不成立时不跳转。两种情况均链接到 PC+8。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
A ← GPR[rs]
k ← U32(GPR[rt][1:0])
GPR[31] ← (PC + 8) mod 2^32
if S32(A) < 0:
    target ← UNRESOLVED_TARGET(offset, 2^k)
execute instruction at PC + 4
nextPC ← target if S32(A) < 0 else (PC + 8) mod 2^32
```

## 边界与异常

k 的范围是 0..3，因此附加条数为 1、2、4、8。链接值必须来自本指令 PC，而非取指阶段当前 PC。
