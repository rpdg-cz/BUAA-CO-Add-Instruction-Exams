## 题目：求加和相反数的原码（边界行为缺失）

## 编码与格式

I型：`111110 | rs(5) | rt(5) | imm(16)`，来自来源译码代码。

完整汇编语法未记录；源为rs与符号扩展的16位imm，写rt。

## 描述

将立即数符号扩展后与rs相加，把该和的相反数转换为32位原码（符号位与31位绝对值）再写入rt。原文和代码未明确特殊边界。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
sum ← GPR[rs] + SEXT32(imm)
negative ← -sum
GPR[rt] ← sign_magnitude_32(negative)
// sum的截断时机、超出31位幅值的处理及零的符号尚未给出完整约束
```

## 边界条件

32位原码只能表示幅值至2^31-1。若32位补码和为0x80000000，则相反数幅值为2^31，无法直接装入31位幅值域。不得凭实现方便决定截断、饱和或排除输入。
