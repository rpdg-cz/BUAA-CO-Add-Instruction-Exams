## 题目：检测连续一位段并无条件跳转链接（来源冲突）

## 编码与格式

jiangshiyi译码给出 `opcode=111110`；I型字段为rs、rt、offset。

kie-chi：`cptl rs, rt, label`。

## 描述

共同部分：检测rs低18位中是否出现至少6个连续1；有则链接目的为rt，无则为31；无条件以P0+4为基址按offset相对跳转。链接写入值的记载不一致。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
condition ← exists k in [0,12]: GPR[rs][k+5:k] = 111111
target ← low32(P0 + 4 + SEXT32(offset || 00))
dest ← rt if condition else 31
链接值：jiangshiyi 为 P0+8；kie-chi 的记载为 PC+4（位于 PC←target 之后）
GPR[dest] ← 未能唯一确定的链接值
PC ← target
```

## 边界条件

连续位段可以出现在低18位内任意起点，可重叠；高14位不参与。即使不满足条件也会跳转并链接31。kie-chi未澄清赋值后PC是旧值还是新值，不能据顺序伪代码擅定target+4。

## 课程阶段注意

P4 为 Verilog 单周期 CPU，无分支延迟槽。

P4无延迟槽并不能自动把该自定义指令的链接值改成P0+4；必须先补证原题。
