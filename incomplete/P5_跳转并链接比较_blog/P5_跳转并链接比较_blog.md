## 题目：比较两种目标地址并链接（比较规则缺失）

## 编码与格式

指令名、opcode和完整字段未记录。

汇编语法未记录；使用rs、rt、offset并链接31。

## 描述

来源比较P0加偏移与rs+rt；前者较小时按P0+4加偏移跳转且执行延迟槽，否则跳向寄存器和并作废延迟槽；无论何种情况都链接P0+8。

## 操作

`GPR[n]` 是 32 位寄存器位串，位编号从最低位 0 到最高位 31；`x[h:l]` 包含两端，`||` 表示高位在左的拼接。`S32(x)` 表示将 32 位位串按二进制补码解释；`SEXT32(x)` 表示按原字段最高位符号扩展到 32 位。涉及 PC 时，`P0` 固定指本指令的地址，所有右侧源寄存器均取本指令执行前的值。课程规定的普通 32 位加减法保留低 32 位，不因溢出触发异常；本题显式给出更宽运算或溢出检测时按本题执行。写入 0 号寄存器不改变其恒零状态。

```text
offset32 ← SEXT32(offset) << 2
A ← low32(P0 + offset32)    // 题解比较输入未加4
B ← low32(GPR[rs] + GPR[rt])
GPR[31] ← low32(P0 + 8)
if A < B:                 // 有符号性未给
    execute delay slot
    next_PC ← low32(P0 + 4 + offset32)
else:
    nullify delay slot
    next_PC ← B
```

## 边界条件

题解比较输入与真正相对跳转目标相差4，不能擅自合并成同一值。加法是否在比较前32位回绕、关系比较的有符号性、B非字对齐时的行为未由题干明确。
