## 题目：无符号较大数除以较小数

## 编码与汇编格式

来源编码：`opcode=000000`、`rs[25:21]`、`rt[20:16]`、`rd[15:11]`、`shamt=00000`、`funct=001010`。来源列出rd字段但格式不使用rd，未说明该字段必须为零还是忽略；不得将其作为目的寄存器。

`bds rs, rt`（来源记录）。

## 描述

将两个源寄存器解释为32位无符号整数，以较大者为被除数、较小者为除数，商写LO，余数写HI。来源明确计算占用时间与课程除法相同。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
A ← U32(GPR[rs])
B ← U32(GPR[rt])
N ← max(A, B)
D ← min(A, B)
if D ≠ 0:
    LO ← N div D
    HI ← N mod D
else:
    HI, LO ← UNRESOLVED_DIVISION_BY_ZERO
```

## 边界与异常

A=B且非零时LO=1、HI=0。任何一个源为零都会使除数为零。普通非零除法的商和余数均能用32位表示，不会发生有符号除法溢出。
