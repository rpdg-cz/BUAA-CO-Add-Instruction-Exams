## 题目：循环移位和的无符号比较

## 编码与汇编格式

博客译码代码记录 `opcode=000000`、`funct=000011`，并选择rd写回；其余位域的固定值未记录。该编码仅属于来源所述单题，不可据此替换标准ISA同编码指令。

语义操作数为 `rd、rs、rt`；来源未列汇编示例，不能据此声称恢复了原题的书写顺序。

## 描述

分别求rs、rt全部32种循环移位结果之和，每次累加保留32位；将两个和作为无符号整数比较，大于写1，小于写-1，相等写0到rd。32位累加与无符号比较来自博客所示实现，不是经课程组核定的原题补充。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
SUM32(A) = (Σ(k=0..31) ROR32(A,k)) mod 2^32
L ← SUM32(GPR[rs])
R ← SUM32(GPR[rt])
if U32(L) > U32(R):
    GPR[rd] ← 0x00000001
else if U32(L) < U32(R):
    GPR[rd] ← 0xffffffff
else:
    GPR[rd] ← 0x00000000
```

## 边界与异常

循环移位包含原数本身一次；向左或向右遍历32种移位所得和相同。`-1`写作32位全一。此处与同类crt的有符号比较不同，不应合并成同一语义。
