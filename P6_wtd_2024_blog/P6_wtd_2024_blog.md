## 编码

```verilog
wire wtd = (opcode_DEin == 6'b0 && func_DEin == 6'b000011) ? 1 : 0;
```

即 R 型指令，`opcode = 6'b000000`、`func = 6'b000011`，写 `rd`。

## 描述

> **wtd 指令**：
> 记 temp1 为 `GRF[rs]` 的32种循环移位的和 如：123 + 231 + 321
> temp2 为 `GRF[rt]` 的32种循环移位的和
> `if (temp1 > temp2)` 则 把 1 写入 `rd`
> `else if (temp1 < temp2)` 则 把 -1 写入 `rd`
> `else` 把 0 写入 `rd`
