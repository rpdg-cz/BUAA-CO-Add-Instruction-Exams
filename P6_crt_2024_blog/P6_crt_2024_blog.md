## 题目：循环移位和的有符号比较

## 编码与汇编格式

博客未记录可验证的opcode/funct及完整位域编码；本文不分配编码。

语义操作数为 `rd、rs、rt`；来源字段排列为 `op | rs | rt | rd | func`，未记录各字段编码与汇编书写顺序。

## 描述

分别对rs和rt求全部32种循环右移结果的32位和，按有符号数比较：左侧较小写-1，较大写1，相等写0。此处依据原博客MathJax公式恢复，并用作者明确要求的signed比较解释大小关系。

## 操作

`GPR`为32个32位通用寄存器，0号读恒为零、写入无效。`U32`/`S32`分别表示同一32位位串的无符号/补码有符号解释；`mod 2^32`只保留低32位。位号从最低位0开始。RTL右侧均读取本指令写回前的源状态；未列出的体系结构状态保持不变。

```text
SUM32(A) = (Σ(k=0..31) ROR32(A,k)) mod 2^32
L ← SUM32(GPR[rs])
R ← SUM32(GPR[rt])
if S32(L) < S32(R):
    GPR[rd] ← 0xffffffff
else if S32(L) > S32(R):
    GPR[rd] ← 0x00000001
else:
    GPR[rd] ← 0
```

## 边界与异常

只取每次和的低32位，再作有符号比较。不能用无符号大小关系替代；例如0xffffffff应当解释为-1。旋转量为0对应原数。
