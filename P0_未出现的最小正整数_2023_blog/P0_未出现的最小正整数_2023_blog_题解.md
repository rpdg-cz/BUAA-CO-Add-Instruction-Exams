# P0_未出现的最小正整数_2023_blog — 题解

## 解题思路

五个输入最多覆盖五个不同正整数，因此答案必在 1～6。对 k=1～5，计算 present[k]，表示五个输入中是否至少有一个等于 k。从 k=1 开始取第一个 present[k]=0 的值；若 1～5 都出现，则输出 6。

也可把每个输入解码为表示数值是否出现的位掩码，将五个掩码按位 or，再查找最低的缺失位。若掩码第 0 位代表数值 1，Bit Finder 得到的位置需加 1；额外保留一位表示必然缺失的 6，可以统一处理 1～5 全部出现的情况。

原始输入数值须先解码，不能直接按位 or。0 和大于 5 的输入不置候选位；重复值只将同一个 present 位再次置 1。
