# P0_打分求和电路_2020_blog

## 题目：带教师评分门控的总分计算电路

## 题目描述

设计 Logisim 组合逻辑电路。三个输入均为无符号二进制数；教师评分为零时总分为零，否则输出三个评分之和。

## 端口定义

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| tea | 输入 | 3 | 教师评分，0～7 |
| s1、s2 | 输入 | 各 2 | 两名学生的评分，各为 0～3 |
| total | 输出 | 4 | 总分 |

## 功能

<pre>if tea = 0 then
    total ← 0
else
    total ← tea + s1 + s2
endif</pre>

最大总分为 13，输出应完整表示运算结果。输出由当前输入决定。
