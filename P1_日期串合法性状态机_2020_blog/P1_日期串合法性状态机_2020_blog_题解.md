## 题解

- 用 Verilog 写 FSM：组合逻辑做状态转移 + 时序逻辑做同步/异步复位，框架见博客"基本框架"一节。

```verilog
`timescale 1ns / 1ps
module test(
    input [7:0] char,
    input clk,
    output reg ...
);
```

- 博客给的两个可复用技巧：

```verilog
wire isd = (char >= "0" && char <= "9") ? 1 : 0;   // 通过三目运算减少码量
```

> 可以在 status 0 中进行初始化，这样当遇到 default 时直接将 status 置 0，而无须进行其他操作。
